# Petualangan Si Daun

Media belajar interaktif IPAS Kelas IV: Fotosintesis. Berisi Materi (7 halaman), Simulasi Percobaan (seret dan lepas), Kuis 10 soal dengan skor dan pembahasan, serta tiga level game.

Satu berkas `index.html`, tanpa instalasi. Font memakai Google Fonts, jadi perlu koneksi internet agar tampil sama persis.

## Cara memasang di GitHub Pages
1. Buat repositori baru, lalu unggah `index.html` dan `README.md` ke cabang `main`.
2. Buka Settings, lalu Pages.
3. Pada Source pilih "Deploy from a branch", cabang `main`, folder `/ (root)`, lalu Save.
4. Tunggu 1-2 menit. Alamatnya: `https://NAMA-PENGGUNA.github.io/NAMA-REPOSITORI/`.
